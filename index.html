Academic Project Details (C++11 Mini Project)

This web interface is a clean frontend demonstration/prototype for the B.Tech 2nd Year CSE Mini Project at JSS Academy of Technical Education, Noida.

Core Academic Project Architecture (C++11):

  • Class Book: Encapsulates Book ID, Title, Author, Total Copies, Available Copies, and 3-tier Location (Section, Rack, Shelf).
  • Class Member: Encapsulates Member ID, Name, and issue history.
  • Class Transaction / Circulation: Manages issue dates, 14-day due date calculation, overdue fine logic (Rs. 2/day), and guided return shelving.
  • Data Persistence: Text-file storage / binary file handling (books.dat, members.dat).

C++ Class Definition Sample (For Viva Explanation):

class Book {
public:
    string bookId;
    string title;
    string author;
    int quantity;
    int available;
    string section; // e.g. "CSE"
    string rack;    // e.g. "Rack 4"
    string shelf;   // e.g. "Shelf 2"

    void displayLocation() const {
        cout << "Place at: Section " << section 
             << " > " << rack << " > " << shelf << endl;
    }
};
